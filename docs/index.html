EdgeTerm

A terminal, SSH, FTP & serial client, inspired by WindTerm 受 WindTerm 启发的终端 / SSH / FTP / 串口客户端

Built with Rust + Tauri v2 and a React + xterm.js frontend. The entire SSH stack is pure Rust (russh) — no libssh2, no OpenSSL, no pkg-config. 基于 Rust + Tauri v2 与 React + xterm.js 前端构建。SSH 协议栈由纯 Rust（russh）实现，不依赖 libssh2、OpenSSL 或 pkg-config。

Built for real work为实际工作而生

The WindTerm layout you know, rebuilt on a modern stack. 熟悉的 WindTerm 布局，全新的技术栈。

🕐

Timestamp & Line Gutter时间戳与行号侧边栏

Every output line carries [HH:MM:SS.SSS] and a cumulative line number, with the cursor line highlighted. Four display modes. 每行输出附带 [HH:MM:SS.SSS] 时间戳与累计行号，高亮光标行，提供四种显示模式。

🎨

Rich Color Rendering丰富的色彩渲染

ANSI 16/256/24-bit true color, plus semantic highlighting for plain logs, network addresses, paths, Git diffs, HTTP and JSON. 支持 ANSI 16 色 / 256 色 / 24 位真彩色，并为普通日志、网络地址、路径、Git diff、HTTP、JSON 等提供语义高亮。

🗂️

Filer & Sessions文件浏览与会话管理

A file browser that switches to SFTP for SSH sessions, plus saved connection profiles in collapsible groups — double-click to connect. 文件浏览器在 SSH 会话下自动切换为 SFTP；已保存连接按分组折叠管理，双击即可连接。

📤

Batch Sender批量发送器

Text or hex input, line-by-line or char-by-char, repeat counts, configurable intervals, targeting one or all sessions. 文本或十六进制输入、逐行或逐字符发送、重复次数与间隔可配置，可发送到当前或全部会话。

⚡

ZMODEM TransfersZMODEM 传输

Local, SSH and serial terminals auto-detect ZMODEM. Run rz / sz to move files, binary-safe, in 1 MiB chunks. 本地、SSH 与串口终端自动检测 ZMODEM，运行 rz / sz 即可收发文件，二进制安全，按 1 MiB 分块处理。
